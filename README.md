# AI_POWERED_RESUME_ANALYZER
# Overview
AI Powered Resume Analyzer is a web application built using python and streamlit. It analyzes uploaded resume and extract useful information such as skills aand ATS Score.
# Features
* Resume Upload
* ATS Score Calculation
* Skills Extraction
* PDF Report Generation
# Technologies Used
* Python
* Streamlit
* NLP
* Scikit-learn
# How to run
Install Dependencies
pip install -r requirements.txt
Run Application:
streamlit run app.py
